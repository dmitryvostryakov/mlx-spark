# Первый запуск и передача агенту

## Решения владельца уже приняты

Самостоятельная полная MLX-like библиотека; один Spark первым; Qwen3.8-27B; обучение не выбрасывать;
два Spark с QSFP существуют, но TP=2 только после законченного single-Spark release.
Не задавать эти вопросы заново и не возвращать обсуждение к inference-server.

## Что передать 5.6-Sol / Terra / Luna

Распаковать ZIP в новый пустой каталог. Открыть его как рабочий репозиторий агента. Передать текст
`handoff/MASTER_PROMPT.md`. Имена Sol/Terra/Luna обозначают распределение ролей; пакет не предполагает
какие-либо непроверенные технические характеристики этих моделей и не вызывает закрытые API.
Если доступен один агент, он исполняет роли последовательно с отдельным review-проходом.

Инициализация Git допустима только в новом каталоге; публикация/remotes/push не требуются. Стартовая доставка
не является Git-репозиторием. До commit проверить `.gitignore`, отсутствие credentials и крупных весов.

## Первая сессия Sol

Прочитать AGENTS/CONTEXT, проверить целостность ZIP и выполнить CPU scaffold suite. Затем FND-01.
При отсутствии Spark можно завершить аудит scaffold и подготовить failing contract tests, но аппаратные задачи
не закрывать. После локальной работы на выбранном Spark выполнить FND-02 с read-only inventory.

## Безопасность выбранной машины

Не SSH к известному «второму Spark», не выводить список сетевых интерфейсов, не останавливать процессы,
не обновлять DGX OS, CUDA или драйвер и не менять лимиты системы. Сначала собрать состояние, затем предложить
изолированную совместимую сборку. Обычный build внутри проекта разрешён; системные изменения требуют отдельного разрешения.

## Что пока невозможно запускать

В пакете нет работающей `generate` или `train` для Qwen. Отсутствует production `_core`.
Сначала FND/CORE/AD/NN и модельные задачи; не заменять их алиасом на установленные внешние библиотеки.
Нельзя выполнить GPU benchmark в CPU-only окружении и дописать ожидаемые результаты вручную.

## Неблокирующие неизвестные

IP/SSH, DGX OS, driver/toolkit/cuDNN, свободное место и exact HF revision пока не подтверждены.
Всё перечисленное записано как unknown. Полный plan/scaffold готов без этих данных; выполнение соответствующего
аппаратного/model gate начинается после получения фактов, а не после угадывания значений.
