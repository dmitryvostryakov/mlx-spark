# ADR-0003: Controlled source fork вместо wrapper

Дата: 2026-09-08. Статус: **proposed-engineering-default**.

## Решение
Reuse pinned MIT MLX как исходники, свои binary/package/release; не runtime alias installed MLX.

## Следствия
Нужны source provenance/namespace/ABI audit; owner может сменить реализацию, не уменьшив product scope.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
