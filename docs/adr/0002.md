# ADR-0002: Один Spark первым, TP2 после релиза

Дата: 2026-09-08. Статус: **accepted-owner-scope**.

## Решение
Первая реализация не имеет network/distributed dependency. Два узла в наличии не меняют порядок.

## Следствия
TP2 tasks deferred; никакой QSFP диагностики/NCCL setup в phase1.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
