# ADR-0007: Нет догадок о версиях и пинах

Дата: 2026-09-08. Статус: **accepted-engineering-contract**.

## Решение
Неизвестные target versions и HF SHA остаются null до resolve/review.

## Следствия
Artifact bootstrap работает offline без них; hardware/model gates блокируются честно.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
