# ADR-0010: Безопасная изоляция системы

Дата: 2026-09-08. Статус: **accepted-owner-safety**.

## Решение
No OS/driver/network/service changes, no public publish without separate authorization.

## Следствия
Новые venv/build workspace; explicit network and resource opt-ins.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
