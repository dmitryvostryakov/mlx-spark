# ADR-0006: Полный hybrid state contract

Дата: 2026-09-08. Статус: **accepted-engineering-contract**.

## Решение
State включает GDN/conv/KV/positions/RNG; immutable semantic snapshots.

## Следствия
Rollback требует всех компонентов; KV trim alone недостаточен.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
