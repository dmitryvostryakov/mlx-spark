# ADR-0001: Полноценный самостоятельный framework

Дата: 2026-09-08. Статус: **accepted-owner-scope**.

## Решение
Не ограничивать продукт inference. Обязательны general arrays/transforms/training/SDK; Qwen — first workload.

## Следствия
API matrix и arbitrary toy training становятся release gates; нельзя закрыть проект токенами/сек.

## Изменение
Новое ADR с причиной и impact; не переписывать историю и не менять protected owner constraints молча.
