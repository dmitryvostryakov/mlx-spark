# Security policy

MLX-Spark is an early engineering scaffold. It has no supported release, no security-response SLA, and must not be used for workloads where a security failure could cause harm.

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability-reporting flow when it is enabled for this repository, or contact the repository owner through their GitHub profile. Include a minimal reproduction, affected revision, impact, and any safe mitigation you have identified.

Do not include credentials, private data, full environment dumps, hostnames, IP addresses, hardware serial numbers, or model weights in a report.

The project will acknowledge reports when practical. Fix availability and timelines cannot be promised while the framework remains pre-alpha.
