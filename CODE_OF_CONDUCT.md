# Community standards

MLX-Spark welcomes constructive technical collaboration. Treat contributors with respect; focus review on evidence, code, and ideas rather than people.

Harassment, discrimination, personal attacks, threats, and sharing another person's private information are not acceptable. For a concern that should not be public, contact the repository owner through GitHub rather than opening an issue.

Maintainers may remove comments, issues, or pull requests that violate these standards and may limit participation when necessary to keep the project safe and productive.
