# Evidence

BUNDLE_VALIDATION.md и raw logs описывают реально проведённую проверку scaffolding.
TEMPLATE файлы не являются доказательствами и не проходят release gate.
Будущие runs сохранять в evidence/runs/<task>/ с source/hardware/command provenance.
Не коммитить секреты, private prompts, полные weights и большие profiler traces.
